### 题目：Python 的可变对象与不可变对象有什么区别？

**考察点**：对象模型、默认参数陷阱。

**参考回答**：
- 概念：可变对象创建后可修改内容（list/dict/set），不可变对象不可改（int/str/tuple）。
- 原理：变量是引用；可变对象修改不改变引用，不可变对象“修改”实际是新对象。
- 示例：`def f(x=[]): x.append(1)` 会导致默认列表在多次调用间共享。
- 场景：缓存默认值、函数参数设计。
- 坑：默认参数用 `None` 代替可变对象。

### 题目：什么是 GIL？对并发有什么影响？

**参考回答**：
- 概念：全局解释器锁，保证同一时刻只有一个线程执行 Python 字节码。
- 原理：CPython 的内存管理非线程安全，GIL 简化实现。
- 代价：CPU 密集用多线程无法加速；I/O 等待期间会释放 GIL。
- 场景：爬虫用线程/异步；图像计算用多进程或 C 扩展。

### 题目：`*args` 和 `**kwargs` 分别是什么？

**参考回答**：`*args` 收集位置参数为元组，`**kwargs` 收集关键字参数为字典；调用时 `*` 可展开序列，`**` 可展开字典。

### 题目：装饰器原理是什么？

**参考回答**：装饰器是高阶函数，接收函数返回新函数；`wraps` 保留元信息；常用于日志、鉴权、缓存。

### 题目：生成器与列表的区别？

**参考回答**：生成器惰性求值、节省内存、只能迭代一次；列表立即构造、可随机访问、占内存。

### 题目：`is` 和 `==` 区别？

**参考回答**：`is` 比较对象身份（`id`），`==` 比较值；小整数和短字符串有缓存，但不应依赖。

### 题目：什么是上下文管理器？

**参考回答**：实现 `__enter__` / `__exit__` 或使用 `@contextmanager`，用 `with` 确保异常时也释放资源。

### 题目：`__init__.py` 的作用？

**参考回答**：标记包；Python 3 隐式命名空间包可不写，但显式声明更利于兼容与导出 API。
