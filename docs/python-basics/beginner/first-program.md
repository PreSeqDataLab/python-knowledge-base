# Python 3 教程

Python 3 是 Python 的主要版本，不向下兼容 Python 2。

**查看 Python 版本**  
在命令行执行：  
```bash
python -V
# 或
python --version
```

**第一个 Python 3 程序**  
创建 `hello.py`，内容如下：  
```python
#!/usr/bin/python3
print("Hello, World!")
```
运行：  
```bash
python3 hello.py
```
输出：  
```
Hello, World!
```
Python 文件扩展名通常为 `.py`。
