# AI Agent 与 RAG · 面试

答题框架见 [面试题库](../interview.md)。

### 题目：RAG 的完整流程是什么？

**参考回答**：索引（切分、向量化、入库）→ 检索（问题向量化、召回、重排）→ 生成（拼 Prompt、LLM 输出、引用）→ 评估（召回率、忠实度、延迟、成本）。

### 题目：如何缓解幻觉？

**参考回答**：检索证据注入、要求引用出处、资料不足时拒答、结构化输出、后处理校验；单靠降低温度不够。

### 题目：文档切分怎么选？

**参考回答**：按语义段落优先，常见 300–800 Token 加重叠；表格与代码单独处理；用评估集验证不同策略。

### 题目：向量检索和关键词检索如何选？

**参考回答**：向量擅长语义相似，关键词擅长专有名词与精确匹配；生产常用混合检索加重排。

### 题目：Agent 和 Workflow 有什么区别？

**参考回答**：Workflow 是固定步骤编排，可控可预测；Agent 由模型决定下一步，灵活但难控。优先 Workflow，必要时引入 Agent。

### 题目：Agent 循环为什么要设最大步数？

**参考回答**：防止工具反复调用导致死循环、成本失控与响应超时；同时便于可观测与降级。

### 题目：如何评估 RAG？

**参考回答**：分层评估：检索层看召回率/MRR，生成层看忠实度与相关性，系统层看 P95 延迟与单次成本。

### 题目：上下文窗口不够怎么办？

**参考回答**：切分文档、只传 Top-K 证据、历史摘要压缩、分层检索；不要盲目截断。

### 题目：为什么工具描述很重要？

**参考回答**：模型依据描述决定是否调用及参数怎么填；描述不清会导致误调用或参数错误。
