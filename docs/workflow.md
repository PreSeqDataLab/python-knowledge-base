# 电脑写 / 手机读工作流

## 电脑端：整理与编写

1. 在对应主线文件里按模板补充内容，优先写“坑”和“为什么”。
2. 在项目根目录启动开发服务器：

   ```bash
   npm install
   npm run docs:dev
   ```

3. 手机同局域网预览：官网脚本默认只监听 localhost，需要手机访问时用：

   ```bash
   npx vitepress dev docs --host 0.0.0.0 --port 5173
   ```

   手机访问 `http://<电脑局域网IP>:5173/python-knowledge-base/`。

4. 按提交规范提交，提 PR 合并到 `main`，Actions 自动发布。

## 手机端：阅读、背诵、回顾

- 浏览器打开 Pages 地址，使用“添加到主屏幕”获得近似 App 的体验。
- 碎片时间优先读 [速查手册](cheatsheet.md) 与 [面试题库](interview.md)。
- 遇到不熟的关键词，用导航栏搜索框检索；搜索支持中文分词与标题加权。
- 每天回顾一章的“复习要点”，只在确实遗忘时回看正文。

## 内容维护节奏

| 频率 | 动作 |
| --- | --- |
| 每次学习后 | 更新对应章节的“复习要点” |
| 每周 | 新增 1–2 道面试题、1 条速查 |
| 每月 | 检查链接、合并重复内容、补充实战复盘 |
| 季度 | 评估新增主题是否独立成章或新开主线 |
