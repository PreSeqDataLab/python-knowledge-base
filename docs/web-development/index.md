# Web 开发

从 HTTP 协议到可部署的 FastAPI 服务，重点在“能写、能调、能排障”。

| 层级 | 章节 | 完成标准 |
| --- | --- | --- |
| 入门 | [beginner.md](beginner.md) | 能看懂 HTTP、跑起服务、写出带参数和请求体的接口 |
| 进阶 | [intermediate.md](intermediate.md) | 能用模型、依赖注入、路由组织项目 |
| 实战 | [practical.md](practical.md) | 能交付带校验、鉴权、日志的 CRUD 服务 |
| 面试 | [interview.md](interview.md) | 能说清 REST、异步、状态码与常见故障 |

> 本项目示例：`main:app` 当前监听 `8001` 端口，包含根路由、`public` 与 `admin` 两组路由。
