# Web 开发 · 面试

答题框架见 [面试题库](../interview.md)。

### 题目：REST 的核心约束有哪些？

**参考回答**：客户端-服务端、无状态、可缓存、统一接口、分层系统、按需代码（可选）。重点是“无状态”：每个请求包含全部必要信息。

### 题目：`PUT` 和 `PATCH` 的区别？

**参考回答**：`PUT` 是全量替换，幂等；`PATCH` 是局部更新，不保证幂等。

### 题目：什么是幂等性？举例。

**参考回答**：同一请求执行一次与多次效果相同。`GET`/`PUT`/`DELETE` 幂等，`POST` 通常不幂等。

### 题目：`401` 和 `403` 的区别？

**参考回答**：`401` 未认证（你是谁）；`403` 已认证但无权限（你能不能做）。

### 题目：FastAPI 为什么快？

**参考回答**：基于 Starlette + Pydantic，类型注解驱动校验与序列化，支持原生 `async def`，生成 OpenAPI 而非运行时反射拼装。

### 题目：同步视图和异步视图怎么选？

**参考回答**：涉及大量 I/O 等待用 `async def` 并 `await` 异步库；CPU 密集或只有同步库时用 `def`，FastAPI 会放到线程池。

### 题目：依赖注入解决了什么问题？

**参考回答**：复用公共逻辑（鉴权、数据库连接、分页），降低视图函数耦合，测试时可替换依赖实现。

### 题目：`422` 是怎么产生的？

**参考回答**：请求参数未通过 Pydantic/类型校验，FastAPI 返回结构化错误信息。

### 题目：接口响应很慢，怎么排查？

**参考回答**：先看链路（浏览器/网关/服务/数据库）→ 看日志与时间打点 → 确认是否 N+1 查询或阻塞 I/O → 再考虑缓存与并发。
