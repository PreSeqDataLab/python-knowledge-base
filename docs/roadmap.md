# 学习路线图

四条主线并行推进，每条主线按四层递进。建议先完成 Python 基础入门，再按角色选择主线。

| 层级 | Python 基础 | Web 开发 | AI Agent 与 RAG | 计算机与必要基础 |
| --- | --- | --- | --- | --- |
| 入门 | 环境搭建、语法、数据类型 | HTTP、第一个 FastAPI 应用 | LLM API 调用、Prompt 基本结构 | 网络模型、Git、命令行 |
| 进阶 | 面向对象、模块、并发 | 依赖注入、校验、中间件 | 工具调用、Agent 循环、记忆 | 数据结构、复杂度、数据库基础 |
| 实战 | CLI 工具、包管理 | CRUD API、鉴权、部署 | RAG 最小系统、评估与优化 | 调试、性能分析、排障案例 |
| 面试 | 可变对象、GIL、装饰器 | REST、状态码、异步模型 | RAG 流程、幻觉与评估 | 计网/OS/算法高频题 |

## 推荐顺序

1. `Python 基础 / 入门` → 能写脚本处理日常任务。
2. `计算机与必要基础 / 入门` → 能看懂报错、会用 Git。
3. `Web 开发 / 入门 + 进阶` → 能独立写 API。
4. `Web 开发 / 实战` → 能部署并排查线上问题。
5. `AI Agent 与 RAG / 入门 + 实战` → 能搭建可评估的 RAG Demo。
6. 任意主线的 `面试` 层 → 用问题反向补齐知识漏洞。

## 完成标准

- 能独立实现一个小型项目并讲清设计取舍。
- 能对着 [面试题库](interview.md) 说出关键原理与常见坑。
- 能在 [速查手册](cheatsheet.md) 中找到常用命令与模板。
