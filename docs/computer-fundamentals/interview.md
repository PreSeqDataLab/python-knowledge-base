# 计算机与必要基础 · 面试

答题框架见 [面试题库](../interview.md)。

### 题目：TCP 三次握手与四次挥手为什么不同？

**参考回答**：握手要确认双方收发能力，三次足够；挥手时被动方可能还有数据要发，因此 FIN 与 ACK 分开，形成四次。

### 题目：HTTP 与 HTTPS 区别？

**参考回答**：HTTPS 在 HTTP 与 TCP 之间加 TLS，提供加密、身份认证与完整性校验，默认端口 443。

### 题目：进程和线程区别？

**参考回答**：进程是资源分配单位，线程是 CPU 调度单位；线程共享进程地址空间，切换成本更低但需同步。

### 题目：什么是 ACID？

**参考回答**：原子性、一致性、隔离性、持久性，是事务的四个基本特性。

### 题目：索引为什么能加速查询？

**参考回答**：索引通常用 B+ 树等结构把无序查找变为有序查找，减少全表扫描；代价是额外存储与写入维护。

### 题目：`O(1)` 一定比 `O(n)` 快吗？

**参考回答**：不一定。大 O 描述增长趋势，常数因子、数据规模与缓存局部性都会影响实际表现。

### 题目：什么是 LRU 缓存？

**参考回答**：最近最少使用淘汰策略，常用哈希表 + 双向链表实现，查找与移动都是 O(1)。

### 题目：如何排查接口变慢？

**参考回答**：分链路定位：客户端网络 → 网关 → 服务 → 数据库/外部依赖；结合日志、指标、链路追踪与慢查询。
