# 计算机与必要基础 · 进阶

## 目标

- 能估算复杂度，理解索引与事务，区分进程与线程。

## 知识点

### 复杂度

| 操作 | 复杂度 |
| --- | --- |
| 数组按下标访问 | O(1) |
| 二分查找 | O(log n) |
| 排序 | O(n log n) |
| 哈希表查找 | 均摊 O(1) |

关注最坏情况与常数因子，不只看大 O。

### 数据库基础

- 索引：类似书的目录，加速查找但拖慢写入。
- 事务 ACID：原子性、一致性、隔离性、持久性。
- 联合索引遵循最左前缀原则。

### 进程与线程

- 进程是资源分配单位，线程是调度单位。
- 线程共享进程内存，需要同步机制。
- 上下文切换有成本，不是线程越多越快。

## 示例：索引是否生效

```sql
-- 假设 (user_id, created_at) 是联合索引
SELECT * FROM orders WHERE user_id = 42 ORDER BY created_at DESC;
```

该查询能利用索引；跳过 `user_id` 直接按 `created_at` 过滤则通常不能。

## 练习

1. 写出两数之和的哈希解法并分析复杂度。
2. 解释为什么 `LIKE '%abc'` 通常无法使用普通 B+ 树索引。
3. 用线程与进程分别做一次计数，观察共享状态差异。

## 复习要点

- 索引不是越多越好。
- 事务隔离级别解决不同读取数据异常。
- 复杂度分析与实际性能都要看。
